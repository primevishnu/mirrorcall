# Security Policy

## Reporting Security Vulnerabilities

We take the security and privacy of MirrorCall very seriously.

If you believe you have found a security vulnerability in MirrorCall, please report it responsibly by contacting the maintainer directly through GitHub Security Advisories or privately to the repository owner at `primevishnu`.

Please include:
- A description of the issue and potential impact
- Steps to reproduce or proof-of-concept
- Any relevant logs or environment details (redacting sensitive IP addresses, setup codes, or credentials)

Do not publish security issues in public issue trackers before a fix is coordinated.
